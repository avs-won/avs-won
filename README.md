### 🎯 What I Built

<table>
  <tr>
    <td width="50%" valign="top">

**🛣️ 4테마 24/7 서버 시스템**

수도고 야간 항주(Highway), 협곡 토우게(Touge), 드리프트(Drift), 랩타임 어택(Laptime)을 각각의 분위기로 분리. 실시간 접속자, 차량/스킨, 라이브 게이지까지 시각화.

**🏆 시즌 챔피언십 운영 도구**

OGT(One Grid Trophy) · WEEKEND 정규 시즌 운영. 라운드별 결과 입력, 포인트 자동 집계, 포디움/명예의 전당까지 자동 렌더링.

**📊 통합 리더보드 & 통계**

Supabase 기반 timing_leaderboard_entries 와 사이트 동기화. 스테이지/차량/컨트롤러 필터, 베스트 섹터(퍼플) 하이라이트, 7,000+ 기록.

  </td>
  <td width="50%" valign="top">

**🗺️ STAGE GUIDE — 인터랙티브 맵**

수도고 맵 이미지 위에 SVG 베지어 경로 직접 드로잉. 관리자 전용 에디터로 구간별 시작/종점, 색상, 방향까지 편집 가능. 미니 리더보드 통합.

**🎨 v1.0-RC UI/UX 전면 리뉴얼**

cyan → blue → purple 네온 컨셉으로 전 페이지 톤 통일. `color-mix()` · `backdrop-filter` · 마스크 그라데이션 보더 등 모던 CSS 적극 활용.

**⚙️ 어드민 풀와이드 콘솔**

6개 그룹 × 2단계 서브 탭으로 운영 효율 ↑. 드래그앤드롭 서버 정렬, 이미지 크로퍼, 슬라이더 관리, 권한 분리(Super/Sub).

  </tr>

### 🧠 Engineering Highlights

| 영역 | 적용 기술 / 해결 사례 |
|---|---|
| **Backend** | Flask Blueprint 모듈화, Supabase Python SDK, ThreadPoolExecutor 병렬 카운트, RuntimeCache snapshot 패턴 |
| **Frontend** | CSS variable 기반 4테마 자동 매칭 (`var(--ac)`), Jinja2 매크로 + body_class 스코핑, IntersectionObserver lazy fetch |
| **Performance** | LCP 최적화 (hero preload), Skeleton shimmer, `count="exact" + head=True`로 대형 테이블 카운트 안정화 |
| **Infra** | Vercel 자동 배포(Webhook), `VERCEL_GIT_COMMIT_SHA` 기반 cache-busting 으로 CDN immutable 캐시 즉시 무효화 |
| **DX** | CSS 번들러 자체 구축 (`tools/build_css_bundle.py`), 죽은 CSS/JS 자동 탐지 스크립트 |
